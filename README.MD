# Skystore - Интернет-магазин

## Описание проекта
Skystore - это учебный проект интернет-магазина, разработанный на Django. 
Проект представляет собой площадку для хранения и продажи плагинов и примеров кода.

## Функциональность
- Главная страница с информацией о товарах
- Страница контактов с формой обратной связи
- Обработка заявок с выводом в консоль
- Адаптивный дизайн на Bootstrap

## Установка и запуск
1. Клонировать репозиторий: ```https://github.com/ts19830409/my_online_store_django.git```
2. Создать виртуальное окружение: ```python -m venv venv```
3. Активировать окружение: ```venv\Scripts\activate```
4. Установить зависимости: ```pip install -r requirements.txt```
5. Применить миграции: ```python manage.py migrate```
6. Запустить сервер: ```python manage.py runserver```
